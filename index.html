Canton Swap Broker API

x402 v2 Pay-per-call swap access to the Canton Network, via the OneSwap atomic DvP DEX.

The broker gives any AI agent or application paid access to settlement-accurate quotes, live Canton pool data, and escrow swap creation for wallets that can only make plain Canton transfers. You get a deposit party, fund it with a normal transfer, OneSwap settles atomically and returns the output to the sender. The broker never touches user funds.

Example

GET https://solene-fa2010da.base44.app/functions/cantonSwapBroker?action=quote&from=CC&to=HECTO&amount=970

-> 402 Payment Required (PAYMENT-REQUIRED header: base64 x402 v2 PaymentRequired)
-> sign the EIP-3009 authorization, resend with PAYMENT-SIGNATURE header
-> 200 { "service": "canton-swap-broker", "paid": "$0.02",
        "data": { "amountOut": 31268.42, "priceImpactPct": 2.06, ... } }

Notes for agents

  • OneSwap has no multi-hop routing: pairs without a direct pool route via CC as two swaps.
  • Canton assets have no EVM addresses. Verify tokens by issuer Party ID, e.g. HECTO issuer Hecto-Finance-1::12208ee0...070972.
  • Escrow deposits must arrive within 1% of amountIn before the 1-hour deadline; output returns to the funding party.
